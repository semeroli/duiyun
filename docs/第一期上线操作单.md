## 第 1 步：建表（约 2 分钟）

数据库现在是空的，得先把「放数据的抽屉」做出来。

1. 打开 Cloudflare 控制台 → 左侧 **存储和数据库** → **D1** → 点进 **duiyun**
2. 上方选 **控制台**（有的界面写 Console / Query）
3. 打开本项目的 `migrations/0001_init.sql`，**整个文件全选复制**
4. 粘进那个输入框，点 **执行 / Run**

**成功的样子**：提示执行成功，没有红字。

**如果看到 `table xxx already exists`**：说明你已经跑过一遍了，属正常，不用管。

### 跑完请核对一下（可选但建议）

在同一个输入框里粘贴这一句并执行：

```sql
SELECT name FROM sqlite_master WHERE type = 'table' ORDER BY name;
```

应当看到这 8 个名字：`comments`、`favorites`、`histories`、`meta`、`posts`、`rate_limits`、`sessions`、`users`。

## 第 2 步：注册你自己，然后把你变成管理员（约 3 分钟）

安全上不能让任何人「注册时勾选我是管理员」，所以第一个管理员只能手动指定。

1. 网站打开 **注册** 页，用你常用的邮箱注册一个账号（记住密码，至少 8 位、要有字母和数字）
2. 回到 D1 控制台，粘贴执行下面这句（**把邮箱换成你刚注册的那个**）：

```sql
UPDATE users SET role = 'admin' WHERE email = '你注册用的邮箱@example.com';
```

> 现成的模板在 `migrations/0002_promote_admin.sql`，那里还附了几条以后可能用到的语句。

3. 刷新网站页面 → 右上角点你的昵称 → 菜单里会多出一项 **管理后台**

## 万一出问题

| 现象 | 多半是什么原因 | 怎么办 |
|---|---|---|
| 页面能开，但注册时提示失败 | 第 1 步的建表没跑成功 | 回第 1 步重新执行一次 `0001_init.sql` |
| 注册后菜单里没有「管理后台」 | 第 2 步那句 SQL 的邮箱写错了 | 重跑一遍 `UPDATE`，注意邮箱不区分大小写 |
| 提示「尝试太频繁了」 | 防刷机制，密码试错次数太多 | 等 15 分钟自动解除；着急的话在 D1 执行 `DELETE FROM rate_limits;` |
| 博客页显示「还没有发布的文章」 | 正常，说明还没有已发布的文章 | 去管理后台写一篇，点「发布」再「保存」 |
